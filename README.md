# 物理ラボ3D

高校物理（物理基礎・物理）の現象を、**3Dで動かして見る**Webアプリです。
`index.html` 1ファイルだけで動きます（インストール不要）。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/physics-simulator/

見た目と画面の構成は「分子ラボ3D（chemistry-simulator）」とそろえています。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開く
2. 左の一覧から実験をえらぶ（力学・熱・波・電磁気・原子）
3. 右のパネルのスライダーを動かすと、3Dの実験がその場で変わる
4. 3Dは **ドラッグで回転**、**ホイール／ピンチで拡大**、右ドラッグで平行移動

> 立体表示の部品（three.js）とフォントはインターネットから読み込みます。授業で使うときはネットにつながった状態で開いてください。

## 画面の構成

- 画面上は **実験／授業／計算／クイズ** の4つだけ。
- 3Dの下に **再生・一時停止・コマ送り・はじめから・スロー（×0.1／×¼）** のバー。スペースキーで一時停止、R キーではじめから。
- 右のパネルは「やってみる」「しくみ・公式」「ポイント」の3つのタブ。
  - やってみる：スライダー・切りかえ、測定値（その場で変わる）、グラフ、エネルギーのバー
  - しくみ・公式：現象の説明と公式
  - ポイント：○×でまとめた要点と「テスト・入試に出るポイント」、その単元の計算問題へのボタン
- 各実験に「やってみよう」の課題。達成すると ✓ がつく（ブラウザに保存）。

## 授業モード（教科書の順）

画面上の「授業」から。**物理基礎 10 の授業**と**物理 14 の授業**が、教科書の順（編・章）に並んでいます。上のタブで科目を切りかえます。

- 授業を始めると左の一覧が消え、大きな文字の説明と3Dで **1画面ずつ** 進みます。教科書と同じ手順の**スモールステップ**で、いきなり解説や計算は出しません。
  1. **観察「こんなとき、どうなる？」**：まず 3D を見て、質問（例：「ペンタが滑り台をすべり下りるとき、速さはどうなっている？」）に 3 つの中から予想を選ぶ。選ぶと答えと「なぜ？（3D で起きていること）」が出る。むずかしいときは「かみくだいた説明を読む」。最後に「式にすると？」で初めて式が出る。「3D で自分で条件を変えてみる」で、その場で試せる。
  2. **例題「公式にしてみよう」**：ボタンを押すたびに ① わかっていること → ② 使う式 → ③ 計算（なぜそうするか つき）→ 答え と、1 手順ずつ出る。
  3. **類題「計算してみよう」**：例題と同じ形で数字だけ変わった問題を自分で解く。まちがえてもヒントつきでもう一度。
  4. **応用問題**：一歩すすんだ問題（2 段階の計算・逆算・考え方の組み合わせ）。
  5. **発展問題（チャレンジ）**：入試に近い問題。「発展問題をとばしてテストへ」も選べる。
  6. **確認テスト**
- **問題は「学習のレール」で、式を自分で立てる**（例題・類題・応用・発展、計算モードも同じ）。1 画面に 1 つのことだけ。
  1. **何を求める？**：問題文の数字は**オレンジ**、求めるもの（「何秒か」など）は**青**。記号の 3 択で「求めるもの」を選ぶ。
  2. **使う式は？**：式のカード 3 枚（記号の式と「ことばの式」つき）から選ぶ。例題ではヒントが先に出る。
  3. **式に数を入れる**：□ を選んで、下のオレンジの札（h = 15 m など）をタップして入れる。まちがった札は赤くなる。
  4. **計算する**：例題はボタンで 1 行ずつ。類題・応用・発展は答えを入れる（「計算のヒント」で解き方の行を 1 つずつ出せる）。
  5. **3D で確かめる**：答えが出ると 3D が動き出し、時間や数字と答えを見くらべる。
  - 3D はその問題の数字で作られ、**止まったまま**、同じオレンジの名札（例：建物の横に h = 15 m）だけが出る。ほかの名札・いまの式・凡例はかくす。
  - 「なぜこの式？」「まちがえやすい所」は、たたんで下に置く。
- 授業の流れ：**導入**（こんなとき、どうなる？ → 予想 → 答え → 式）→ **例題**（いっしょに式を立てる）→ **類題**（数字をかえて自分で）→ **応用**（式を立てて解く）→ **発展**（チャレンジ）→ **テスト**。
- 観察のページでは、「式にすると？」を押すまで「いまの式」を出さない（先に現象を見る）。
- 全 24 授業に、例題・類題・応用・発展の問題がある（計算問題は全 78 種類。数字は毎回変わる）。
- 大きな「次へ」ボタン（キーボードの → でも同じ）を押していくだけで、この順に進む。上の「観察／例題／類題／応用／発展／テスト」の印で、いまどこかわかる。
- 授業の最後の画面に「テスト・入試に出るポイント」。
- 確認テスト：各授業に4問（全96問）。3問以上正解で合格のはんこ。合格すると「次の授業 →」。「テストをとばす」で次の授業へ進める。一覧の「テスト」ボタンでテストだけもできる。
- 見終わった授業には ✓、合格した授業には はんこ。「続きから」で次の授業を始められる。
- 授業中は、終わった実験（ボールが地面に着いたなど）が少し待ってから自動でくり返す。
- 授業中に右上の全画面ボタンを押すと、説明パネルもいっしょに全画面になる（プロジェクター向け）。
- 授業の一覧の下の「学習の記録を消す」で、✓・合格・正解の記録をすべて消せる（次の学年に使うときなど）。
- 実験の「ポイント」タブから、その実験を使う授業へ飛べる。

## やさしい授業（試作）：自由落下

授業の一覧のいちばん上の「新しい形の授業（試作）」から。物理や計算が苦手な人向けに、1画面に1つのことだけを出す新しい形です。

- ペンタが 3D の中の吹き出しで話す。下のボタンは1つだけで、スクロールしなくてよい。
- 流れ：予想（3D は止めたまま）→ スローで見る → 1秒・2秒・3秒で自動で止まって「何 m 落ちたか」を数える → 表 → きまり（時間が2倍で距離は4倍）→ ことばの式「落ちた距離 ＝ 4.9 × 時間 × 時間」→ 教科書の式 y = ½gt²（記号の意味つき）→ 例題 → 穴うめ → 逆算（4.9 で割る → √）→ まとめ → 確認テスト
- 計算は空らんをうめる形。途中の数も1つずつ入れる。電卓の押し方（÷ → √）も見せる。
- まちがえると理由を1文で教える（「時間は2回かける」「√ を押そう」など）。「その時間で 3D を止めてみる」で、ボールがまだ空中か、もう着いているかを見られる。
- 計算した答えは、毎回 3D を動かして確かめる。

ほかの授業もこの形にするかどうかは、試作を使ってみてから決める。

## 授業の見やすさの直し

- 観察の予想を選ぶまでは 3D を止めておく（先に答えが見えないように）。
- 自由落下では向きを「↓ 下向き 12.7 m/s」のように言葉と矢印で出し、マイナスを使わない。「いまの式」も下向きを＋にした v = gt にそろえた。
- 「次へ」ボタンを画面の下に固定。確認テストのとき、前の問題の 3D が残らないようにした。
- ストロボの残像をオレンジにして見やすくした。

| 斜面 | 公園の滑り台／スキー場（雪の斜面と木）／坂道（アスファルトと勾配の標識） |

## 3D の見た目（影・空・地面）

- 太陽の光で物や人の**影**が地面に落ちる。外の実験（校舎・公園の滑り台・ブランコ・ボール投げ）は**青空と草地**、ほかは実験室。地面は遠くで空の色にとけこむ。
- 動きが重い端末では、自動で画面の細かさを下げ、それでも重いときは影を省く。

## キャラクターと「いまの式」

- **キャラクター「ペンタ」**：アデリーペンギンをモデルにした、物理ラボの研究員。黒い頭と背中、くっきり白いおなか、目のまわりの白い輪、平たいつばさ（内側は白）、ピンクの水かき（指3本とつめ）。大きな目にハイライト、うっすら赤いほっぺ。くちばしは本物と同じく黒く、下のふちだけオレンジ。ときどきまばたきして、首をかしげたり、つばさをパタパタしたり、きょろきょろ見回したり、ぴょんと小さく跳ねたりする。首のスカーフの色（緑・オレンジ）で2羽を見分ける。ペンギンは氷の上をおなかですべる動物なので、摩擦と慣性の話にぴったり。
  - 関節ひとつひとつがばねのように動き、体が急に止まったり動き出したりすると、上体が慣性で前後にゆれる（物理エンジンのような動き）。
  - 例：校舎の屋上からボールを落とす／サッカーボールをけって飛ばす／**滑り台**にすわってすべる／**バンパーカー**に乗ってぶつかる／**公園のブランコ**をこぐ／ハンマー投げのように回す／ピストンを押す／ひもをゆらして波を送る／レーザーを持ってねらう／磁石を持ってよちよち歩いて出し入れする
  - レンズでは、物体がペンタ。スクリーンには、さかさまで小さい「すけたペンタ」が映る。
- **いまの式**：3D の動いている物のそばに、いま使っている式と、その瞬間の数字を入れた計算を表示（例：v = v₀ − gt = 0 − 9.8×1.20 = −11.76 m/s）。止まっているときと動いているときで式が切りかわる（斜面の「つり合い」→「運動方程式」など）。3D の左下にまとめて出すので、動いている物をかくさない。スマホなど画面がせまいときは 1 行だけ出し、タップすると全部出る。右上の「式」ボタンで表示・非表示。

## 物理が苦手な人のために

- **かみくだくと**：授業の全画面（108 画面）と、実験の「しくみ」タブに、身近なたとえを使ったやさしい説明（ジェットコースター、救急車のサイレン、なわとび、ブランコなど）。
- **計算のサポート**（計算モードと、授業の「練習」の両方）
  - ① わかっていることを書き出した表と「求めるもの」
  - ヒントを 1 つずつ見られる（各問題 2〜3 段階）
  - まちがえても、もう一度答えられる。答えの数から原因を推測して教える（「√ をとり忘れている」「½ をかけ忘れていないか」「単位の変換は？」「開管の式を使っている」など）
  - 答えのあとに、1 行ずつ「なぜそうするか」つきの解き方、「なぜこの式を使うの？」、「まちがえやすい所」

## 計算（78種類）

数字が毎回変わる計算問題。答えを入れると正解か判定し、解き方を表示します。
「1.2×10^5」「1.2e5」の形でも入力できます。うしろの3Dは、**その問題の数字どおり**に作り直されて動きます（左上に「図：この問題の数字」）。授業の例題・類題・応用・発展の問題も、ここから自由に選べます。
　ほか、授業ごとの応用・発展問題（熱量・電磁誘導・干渉・電場と電位・オームの法則など）
自由落下・投げ上げ・水平投射・斜方投射・斜面の加速度・衝突・ばね振り子・単振り子・向心力・第1宇宙速度・状態方程式・ボイルシャルル・v = fλ・閉管・ドップラー効果・屈折・臨界角・レンズの式・並列回路・磁場中の円運動・光電効果

## クイズ

考え方を確かめる4択問題（37問）。1回10問。分野をえらべます。答えると解説と「実験で確かめる」ボタンが出ます。8問以上で合格のはんこ。

## しくみ（先生向けメモ）

- 運動は、決まった小さな時間ごとに計算しています（運動方程式をそのまま数値計算）。単振り子は sin θ のまま計算するので、振れ角が大きいと周期が公式より長くなります。
- 磁場中の荷電粒子はボリス法で計算しているので、速さが変わりません。
- 気体の分子どうしの衝突は省略しています。圧力は、かべが受けた力積から求めています。
- URLの最後に `#proj` のように付けると、その実験を開いた状態のリンクになります（ID は `index.html` の `sim({ id: ... })`）。

## 見た目

分子ラボ3D と同じ「理科の実験ノート」の見た目。紙の方眼の背景・墨色の文字・明朝体の見出し・緑青（アクセント）と朱（強調）。床は方眼紙（1マス = 1目盛り）。ダークモードは黒板（深緑）の色。
